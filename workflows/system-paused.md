# Временная граница остановленных маршрутов

Этот файл применяется только к маршрутам, у которых в текущем system/manifest.yaml указан workflow-paused. Он не относится к активным email-new-build и email-continue-fix: для них manifest назначает workflow-email-build.

Остановленный маршрут допускает навигацию и read-only анализ относящихся к нему структурированных источников, а при необходимости — read-only Figma MCP. Он не разрешает production-сборку письма, изменение готового письма или автоматическую запись в Figma. Если resolver возвращает SKILL_ROUTE_PAUSED, нельзя подставлять workflow другого маршрута.

Точечная работа по миграции или источникам выполняется только по согласованной области с проверкой влияния и результата. Оставшиеся маршруты включаются отдельными проверенными этапами по roadmap; этот файл не меняет статус активных email-маршрутов.
