# Временная граница рабочих маршрутов

Этот документ применяется только к маршрутам, чей `workflow_source_id` в manifest закреплённого SHA равен `workflow-paused`. Такой маршрут служит для навигации и проверки структуры данных и не разрешает production-сборку письма, автоматическую запись в Figma или изменение готового письма по неполному процессу. Состояние одного остановленного маршрута не определяет состояние остальных.

Для read-only вопроса разрешается читать только относящиеся к нему структурированные источники и, если нужно, фактические данные Figma через MCP. Для изменения данных сначала требуется точная область разрешённых файлов или Figma-полей, проверка влияния на зависимые источники и отдельная проверка результата.

Полноценные процедуры поддержки библиотеки и сборки письма будут подключены отдельным изменением после завершения их структурированных контрактов и локальных проверок. Пока такого подключения нет, маршрут должен возвращать состояние «не готов», а не подставлять другой набор правил.
