[Общие требования](../specs/2026-10-11-altcraft-html-release.md) и [принцип организации исходника по агентским файлам](../specs/2026-10-11-altcraft-html-authoring-principles.md) сопровождают каждый план. Компонентные контракты и Фигма не меняются. Техническая логика должна принадлежать коду и машинным данным, навыки остаются тонкими.

Отдельного пятого этапа с импортом, отправкой и почтовиками нет: доступа к полной цепочке у агента не будет. Локальные кодовые и визуальные проверки входят в каждый этап; внешнюю проверку команда может выполнить отдельно. До её результата внешний статус — «не выполнено».

GitHub Actions и PR Checks не используются. Рутинные проверки и визуальные сравнения выполняет Terra medium локально. Профиль ПК не собирается заново. Недостающие адреса футера и NPS остаются обязательными входами, не заменяются заглушками. Новый PR не сливается автоматически.
