## Проверка потребителей и покрытия

Инвентаризация охватывает package scripts, manifest source/profile/route registration, current scripts imports/reads, repo-scoped skills, bootstrap и current tests. Старые test/CLI copies ссылаются только на прежний layout и друг на друга; они исключены из package test. Их собственные импорты старых helper-файлов не делают архив production consumer. Исторические journal/provenance ссылки сохраняются как ссылки на прошлые commits. Постоянные schema/status/authorization guards не ослабляются.

Current `tests/characterization/html-rendering-shadow.test.mjs` сохраняет обе проверки архивных workflow digests и structured responsibility assertions. Component migration adapter/mapping остаются вместе с активным `component-documentation-migration.test.mjs`. Из current characterization-boundary test снимается только истёкший запрет закрыть 11C; no-Legacy paths, workflow mapping, pilot coverage и самостоятельность cleanup duties сохраняются.

## Проверки и ограничения

На exact final cloud commit выполняются local validator, generated check, полный семигрупповой Node suite и Windows bootstrap verifier/contract tests без установки. Дополнительно проверяются все route/mode outputs, отсутствие runtime owners в Legacy/removed paths, полный allowed-path diff, сохранившиеся10 baseline blobs и обе backup refs. Source byte identity current renderer/data гарантирует отсутствие изменения HTML/design; новую визуальную съёмку для такого diff не заявляем. Actions/PR Checks, повторный сбор профиля ПК, установка навыков, Figma и реальные письма не входят в пакет. Импорт/отправка/реальные почтовики остаются not-run.
